品牌策略 · 文稿与方案阶段

Pink Logic · 从品牌到脚本

01 / 项目的问题

怎样把品牌想表达的情绪，落到每一条可拍摄的内容？

02 / 如何展开

串联品牌定位、受众、脚本、达人共创与运营复盘；将人物关系、拍摄场景和镜头节奏写进脚本。

03 / 已形成的内容

品牌内容系统、三种短视频脚本与分阶段内容日历。日历前半段有具体选题，后半段仍待细化。

根据项目资料编辑整理

方法展开 · 编辑整理示意

  1. 30秒脚本结构：人物与场景 → 照片展示 → 人物反应 → 产品入镜 → 互动问题
  2. 故事方向：记录家人；由关系与情绪推动画面
  3. 内容排期：将拍摄、审核和发布状态分开管理

04 / 复盘与下一步

现有资料以待拍摄方案为主。后续用真实成片替换脚本示意，并核对产品表达。

01 / 项目的问题

怎样让合作沟通清楚，同时为创作者保留自己的表达？

02 / 如何展开

将合作信息、内容方向、交付要求、审核与反馈整理为统一流程，再按合作类型补充说明。

03 / 已形成的内容

达人合作 Brief、沟通模板与健康体验官招募文案。

根据项目资料编辑整理

方法展开 · 编辑整理示意

  2. 内容过程：选题 → 初稿 → 反馈 → 确认
  3. 体验记录：以14天日记组织观察与反馈

04 / 复盘与下一步

补齐实际合作笔记与授权素材。招募文案中的人数是计划目标，当前不作为完成数据展示。

大威宠 · 产品表达与市场研究

01 / 项目的问题

怎样从产品资料出发，讲清楚消费者关心的使用场景？

02 / 如何展开

沿着资料证据、生活问题、表达方式与内容渠道逐层整理；将国内外竞品观察用于提出可验证的方向。

03 / 已形成的内容

市场竞争分析报告、除臭喷剂卖点整理与曝光方案。

根据项目资料编辑整理

方法展开 · 编辑整理示意

  1. 资料层：原始配方信息与可支持的表达分栏
  2. 场景层：猫砂盆周边、窝垫与外出空间
  3. 内容层：详情页结构 → 短视频开场 → 常见问题

04 / 复盘与下一步

方案中的定位建议尚待采纳；具体功效与市场判断需回到产品证据和实际反馈。此处展示研究与表达结构。

  3. 第二阶段：挑战与冲突；第三阶段：阶段收获

ROI Brain Engine · 内容复盘框架

01 / 项目的问题

怎样让每一次内容尝试，为下一次选择留下依据？

02 / 如何展开

城市商业观察 · 账号拆解方法

01 / 项目的问题

怎样从参考内容中提炼方法，再形成自己的观察？

02 / 如何展开

对照标题、封面、场景与正文结构，把样本观察转化为栏目方向、选题池与封面 Brief。

03 / 已形成的内容

账号拆解报告、内容方向、排期建议与封面提示词库。研究对象的作品不作为本人作品展示。

根据项目资料编辑整理

方法展开 · 编辑整理示意

  1. 观察维度：具体项目、现场证据与问题句
  2. 输出结构：场景 → 变化 → 判断 → 可借鉴的方法
  3. 应用方向：商业空间、街区更新、主理人品牌与路线观察

04 / 复盘与下一步

原始样本主要包含点赞与封面信息，不能据此推断转化效果。下一步接入自己的实地观察与发布作品。

六顶思考帽 · 讨论与复盘模板

01 / 项目的问题

怎样让个人思考和团队讨论更有条理？

02 / 如何展开

基于六顶思考帽方法，将事实、感受、风险、价值、替代方案与行动整理为填写提示。

03 / 已形成的内容

个人与团队通用的结构化讨论模板；属于既有方法的应用整理。

根据项目资料编辑整理

方法展开 · 编辑整理示意

  1. 先分开写：已知事实、个人感受与担忧
  2. 再扩展写：可能的价值与其他做法
  3. 最后收束：本次决定、责任人与复盘时间
